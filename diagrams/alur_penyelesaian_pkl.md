## 1. PENJELASAN TAHAPAN PELAKSANAAN PKL

Alur penyelesaian kegiatan Praktik Kerja Lapangan (PKL) / Tugas Akhir ini disusun secara sistematis dalam alur lurus vertikal mencakup tahapan-tahapan utama:

1. **Mulai:** Inisiasi kegiatan PKL di Kantor Imigrasi Kelas I Non-TPI Bogor.
2. **Observasi & Pengumpulan Data:** Mengumpulkan data operasional logistik melalui wawancara langsung dengan kasir dan studi dokumen pencatatan paspor koperasi.
3. **Analisis Permasalahan & Kebutuhan:** Mengidentifikasi kendala pada proses manual dan merumuskan spesifikasi kebutuhan perangkat lunak (kebutuhan fungsional & non-fungsional).
4. **Perancangan & Functional Prototyping:** Merancang cetak biru sistem menggunakan UML (Use Case, Activity, Sequence), ERD basis data, serta antarmuka (UI).
5. **Implementasi & Pemrograman:** Membangun basis kode aplikasi menggunakan framework Laravel 11 (PHP 8.4), MySQL 8.0, dan Node.js Baileys WhatsApp Gateway.
6. **Pengujian Sistem:** Melakukan validasi fitur dengan metode Black Box Testing dan User Acceptance Testing (UAT) bersama kasir koperasi.
7. **Deployment & Go-Live:** Memasang dan mengkonfigurasi aplikasi pada server produksi VPS Ubuntu 22.04 LTS dengan web server Nginx.
8. **Penarikan Kesimpulan & Laporan:** Menyusun dokumentasi akhir dan laporan resmi PKL/Skripsi.
9. **Selesai:** Pelaporan hasil kegiatan secara resmi.
