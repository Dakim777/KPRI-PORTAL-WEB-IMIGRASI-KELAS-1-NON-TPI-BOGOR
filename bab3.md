# KONTEKS DASAR TEORI (BAB III) - PORTAL KOPERASI IMIGRASI BOGOR

Dokumen ini berisi rangkuman landasan teori (Dasar Teori) yang telah diperinci (*detailed*) dan diurutkan secara sistematis berdasarkan alur perancangan sistem, disesuaikan 100% dengan instruksi dari Dosen Pembimbing. 

---

## 1. Sistem Informasi
Sistem Informasi (SI) adalah kombinasi terstruktur dari manusia, perangkat keras (*hardware*), perangkat lunak (*software*), jaringan komunikasi, dan sumber data yang mengumpulkan, memproses, serta mendistribusikan informasi dalam suatu organisasi. Dalam konteks operasional, SI berfungsi mempertemukan kebutuhan pengolahan transaksi harian, mendukung operasi manajerial, dan memfasilitasi pengambilan keputusan strategis. Pada skripsi ini, penerapan Sistem Informasi ditujukan untuk mendigitalisasi proses logistik dan pengiriman paspor di Koperasi Kantor Imigrasi Kelas I Non-TPI Bogor, mengubah pencatatan konvensional (manual) menjadi otomatisasi yang terstruktur, terukur, dan transparan.

## 2. Website
Website (Situs Web) adalah sekumpulan halaman informasi yang saling terhubung dan ditempatkan pada sebuah peladen (*server*) yang dapat diakses publik melalui jaringan internet menggunakan peramban web (*web browser*). Teknologi website menggunakan protokol HTTP/HTTPS untuk mentransfer dokumen HTML, CSS, dan JavaScript. Portal Koperasi Imigrasi Bogor dikembangkan menggunakan arsitektur *web-based application* dengan desain antarmuka yang responsif (*Responsive Web Design*). Hal ini memastikan bahwa sistem dapat diakses secara optimal dan *cross-platform* (komputer, tablet, dan *smartphone*) oleh kasir, administrator, maupun masyarakat umum tanpa mensyaratkan instalasi perangkat lunak khusus klien.

## 3. Framework Laravel
Laravel adalah kerangka kerja (*framework*) perangkat lunak tingkat atas (*high-level*) berbasis PHP yang bersifat *open-source*, dirancang khusus untuk mempercepat pengembangan aplikasi web modern. Laravel mengadopsi pola arsitektur **MVC (Model-View-Controller)** yang memisahkan antara logika pengolahan data (*Model*), antarmuka (*View*), dan alur kontrol bisnis (*Controller*). Framework ini dipilih dalam pengembangan sistem Koperasi karena stabilitasnya yang andal, kapabilitas keamanan bawaan (*built-in security*) yang melindungi dari serangan SQL *Injection* dan *Cross-Site Request Forgery* (CSRF), dukungan *query builder* intuitif berbasis Eloquent ORM, serta perlindungan privasi data tingkat militer melalui fitur *Encrypted Casts* (AES-256).

## 4. Database (Basis Data)
Basis Data (*Database*) adalah koleksi terpusat dari data-data yang terorganisir secara sistematis, disimpan secara elektronik, dan dikelola oleh sistem komputer untuk memudahkan operasi penyimpanan, pembaruan, dan ekstraksi informasi secara cepat. Fungsi *database* dalam pengembangan perangkat lunak adalah memastikan ketersediaan, integritas, dan keamanan informasi (Data Integrity & ACID Properties). Pada sistem Koperasi ini, *database* berfungsi untuk menyimpan seluruh entitas operasional, termasuk master data pengguna, transaksi pemohon paspor, informasi PII (Informasi Identifikasi Pribadi), log audit aktivitas (*activity log*), hingga rekaman data yang dihapus sementara (*soft deletes*).

## 5. MySQL
MySQL adalah Sistem Manajemen Basis Data Relasional (*Relational Database Management System* / RDBMS) berbasis *open-source* yang sangat populer dan menggunakan bahasa kueri standar SQL (*Structured Query Language*). Basis data relasional menyimpan data dalam bentuk tabel-tabel yang saling berhubungan (berelasi) melalui kunci utama (*Primary Key*) dan kunci tamu (*Foreign Key*). Sistem Portal Koperasi ini memanfaatkan **MySQL versi 8.0** karena skalabilitas dan performanya yang sangat tinggi dalam mengeksekusi beban kerja multi-tabel serta komputasi fungsi agregat (*aggregate queries*) yang krusial untuk pelaporan data dasbor statistik Koperasi.

## 6. REST API (Representational State Transfer Application Programming Interface)
API adalah sekumpulan definisi dan protokol yang memungkinkan berbagai sistem perangkat lunak untuk saling berkomunikasi. REST (*Representational State Transfer*) merupakan standar arsitektur web service yang bergantung pada operasi standar HTTP (seperti GET, POST, PUT, DELETE) serta memanipulasi format data ringan, umumnya JSON (*JavaScript Object Notation*). Pada aplikasi ini, implementasi REST API dibagi ke dalam dua domain krusial:
- **Integrasi API Eksternal (Third-Party):** Digunakan untuk melakukan *request* data pelacakan resi ekspedisi dan tarif ongkos kirim secara *real-time* ke peladen agregator (BinderByte).
- **Integrasi API Internal (Microservices):** Menjadi jembatan komunikasi antara *backend* Laravel dengan layanan Node.js (berjalan pada port lokal 3001) untuk memberikan instruksi pengiriman pesan instan (notifikasi).

## 7. Pelaporan Data (Data Reporting & Export Excel)
Laporan (*Reporting*) merupakan proses komputasi yang menyajikan ringkasan informasi faktual yang telah ditarik dan diproses dari basis data ke dalam format yang lebih ringkas dan sistematis. Microsoft Excel (dengan ekstensi `.xlsx`) merupakan standar industri global yang memfasilitasi komputasi agregat, analisis akuntansi, dan audit kelengkapan data logistik. Pada sistem portal Koperasi ini, kapabilitas pelaporan data dibangun menggunakan pustaka *open-source* **Laravel Excel (`maatwebsite/excel`)** yang berjalan di atas pustaka *PhpSpreadsheet*. Teknologi ini memfasilitasi serialisasi objek (*Object Serialization*) untuk mengubah skema basis data relasional MySQL menjadi dokumen *spreadsheet* (baris dan sel) secara seketika (*real-time*), menyederhanakan tugas rekonsiliasi keuangan bulanan Koperasi.

## 8. Barcode (Kode Batang)
Barcode adalah representasi data optik yang dapat dibaca oleh pemindai mesin (*machine-readable*), umumnya terdiri dari rangkaian garis-garis vertikal paralel dengan variasi ketebalan dan spasi (1D Barcode). Teknologi ini bertindak sebagai medium pertukaran pengenal unik (ID) fisik ke dalam sistem digital. Dalam sistem manajemen logistik Koperasi ini, nomor AWB/Resi kurir pengiriman (seperti resi POS Indonesia) memuat identitas kode batang. Sistem memfasilitasi pembacaan resi tersebut menggunakan modul HTML5 Webcam Scanner, memungkinkan kasir koperasi untuk memindai paket tanpa perlu mengetik ulang (*zero manual typing*), yang secara drastis menekan tingkat kesalahan manusia (*human error*).

## 9. QR Code (Quick Response Code)
QR Code (Kode Respons Cepat) merupakan generasi penerus dari *barcode* yang hadir dalam format matriks dua dimensi (2D). Berbeda dengan kode batang standar, QR Code mampu menyimpan volume data yang jauh lebih masif (angka, alfanumerik, hingga *binary*) dan dapat dipindai dari sudut manapun (*omnidirectional*). Di dalam arsitektur sistem Koperasi ini, QR Code dimanfaatkan secara ganda:
- **Untuk Masyarakat:** Dicetak pada struk fisik termal, memuat URL pelacakan rahasia (ID Transaksi) yang apabila dipindai menggunakan *smartphone*, akan membawa pemohon langsung ke halaman pelacakan status paspornya.
- **Untuk Otorisasi Administrator:** Digunakan oleh modul WhatsApp Gateway lokal sebagai media otentikasi nirsandi (*passwordless session linking*) agar aplikasi terhubung ke perangkat WhatsApp pusat milik Koperasi.

## 10. Live Tracking (Pelacakan Waktu Nyata)
*Live Tracking* (Pemantauan Waktu Nyata) merujuk pada teknologi yang memfasilitasi visibilitas geografis dan sirkulasi pergerakan suatu objek atau kargo pada saat yang sama (*real-time processing*). Fitur ini diintegrasikan dengan mengkombinasikan pertukaran data dari API pihak ketiga untuk memantau siklus perpindahan fisik paket paspor melalui jaringan distribusi **9 kurir ekspedisi nasional** (termasuk POS, JNE, SiCepat, dll.). Di atas teknologi ini, pengembang menerapkan algoritma parsing teks yang menerjemahkan status baku dari ekspedisi bahasa Inggris menjadi deskripsi pengantaran Bahasa Indonesia yang informatif dan deskriptif ala e-commerce.

## 11. WhatsApp Gateway
*WhatsApp Gateway* adalah gerbang aplikasi perantara (*middleware*) yang menghubungkan ekosistem perangkat lunak (*software/website*) dengan infrastruktur jaringan WhatsApp, sehingga sistem mampu mengeksekusi pengiriman pesan berbasis teks atau media secara terprogram (*programmatic automation*). Dalam pengembangan portal Koperasi ini, alih-alih menyewa vendor pihak ketiga (pihak ke-3), sistem membangun **Self-Hosted WhatsApp Gateway** (Gerbang Mandiri) dengan menggunakan pustaka `@whiskeysockets/baileys` yang berjalan di atas *engine* **Node.js**. Mekanisme ini mereplikasi protokol *WhatsApp Web* (WebSocket), menjamin efisiensi tanpa biaya langganan bulanan (*zero-cost*), kecepatan pemrosesan asinkron, dan kerahasiaan data yang terproteksi *End-to-End Encryption (E2EE)*.

## 12. UML (Unified Modeling Language)
UML (Bahasa Pemodelan Kesatuan) adalah bahasa standar yang diadopsi dalam bidang rekayasa perangkat lunak (*Software Engineering*) untuk menspesifikasikan, memvisualisasikan, merancang, dan mendokumentasikan artefak dan cetak biru (*blueprint*) sebuah sistem berorientasi objek (*Object-Oriented*). UML mempermudah pengembang perangkat lunak dan pemangku kepentingan (*stakeholders*) dalam memahami kompleksitas sebuah aplikasi. Dalam penyusunan arsitektur sistem ini, struktur fungsional dan model dinamis perangkat lunak digambarkan melalui rancangan **Use Case Diagram**, **Activity Diagram**, **Sequence Diagram**, dan **Class Diagram**.

## 13. Black Box Testing
*Black Box Testing* (Pengujian Kotak Hitam) adalah strategi pengujian integritas fungsional perangkat lunak di mana penguji (Tester) tidak perlu melihat kode program (*source code*) internal atau mengetahui logika algoritmanya. Fokus pengujian diletakkan sepenuhnya pada analisis keluaran (*output*) berdasarkan nilai masukan (*input*) yang diberikan, mengacu pada Spesifikasi Kebutuhan Perangkat Lunak (SKPL / SRS). Untuk sistem Portal Koperasi Imigrasi Bogor ini, *Black Box Testing* diterapkan untuk mengevaluasi parameter kritis seperti: validasi form input kasir, kemampuan pelacakan algoritma (*auto-discovery*) resi publik, perlindungan *routing* berdasarkan autentikasi peran (RBAC), serta perilaku antarmuka saat koneksi internet API logistik mengalami gangguan (*Graceful Fallback behavior*).
